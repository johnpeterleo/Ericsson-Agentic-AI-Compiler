You are a GPU performance engineer. Your goal is a JAX program that returns the same values as a reference program but runs faster on the target device than what the XLA compiler makes of the reference.

XLA already fuses elementwise operations and picks good kernels for each operation. What it does not do is change the algorithm: the order of matrix products, the number of passes over memory, work that can be skipped, large intermediates that need not exist. That is where speedups come from.

## Your task

The folder you are in holds:
- `reference.py`: the program to speed up. Its function `reference` is the ground truth. Do not edit this file.
- `candidate.py`: your rewrite. It must define `candidate`, taking the same arguments as `reference`. It starts as a copy of the reference.
- `check.py`: run `/home/joelmaharena/Ericsson-Agentic-AI-Compiler/.venv/bin/python check.py` to check `candidate` against the reference and time both on the GPU (an NVIDIA L4). Do not edit this file.

Inputs: float32[8, 1024, 1024], float32[1024], float32[1024], float32[1024, 3072], float32[1024, 1024], float32[1024], float32[1024], float32[1024, 4096], float32[4096, 1024]. Tolerance: rtol=0.01, atol=0.01. JAX runs with its default settings.

Rules for code:
- It runs in a namespace that holds only `jax` and `jnp` (jax.numpy). Define every helper and constant you use in your code. You may import other parts of jax.
- Keep float32 arithmetic. Do not compute in bfloat16 or float16, even where the tolerance would allow it. Return the reference's shape and dtype.
- Compute the same function. Do not swap in an approximation (such as the tanh form of an exact GELU) that only passes because the tolerance is loose.
- Pure JAX only: no side effects and no NumPy on traced values. The code is compiled with jax.jit.
- `candidate.py` is run on its own, so it must import what it uses (for example `import jax` and `import jax.numpy as jnp`).

How it is scored: when you are done, `candidate.py` is checked again and timed on an input you have not seen. The speedup there is the result.

Work only inside this folder: do not read or search other folders in the home directory, and do not look up solutions online. You may write any scripts you like here, use the Python interpreter above, and read the installed JAX library. You have about 45 minutes. Finish by leaving your fastest correct version in `candidate.py`, and end with a short summary of what you tried and measured.
